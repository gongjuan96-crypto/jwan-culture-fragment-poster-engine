# Example briefs

The repository currently includes one public render, `case-01.png`. Do not commit a user's private source photo without permission.

## Case 01 — Canonical cultural fragment

Combine a place, object, person, memory, and material cue into one coherent poster with a deliberate focal point.

## Case 02 — Place-led variation

Let the intended place lead the hierarchy while keeping cultural references, typography, and margins controlled.

## Case 03 — Material-led variation

Let one supplied material or object guide the palette and illustration language without adding unrelated decorative elements.
